## Acceptance criteria
- Merchandiser can create an order and TNA.
- Supervisor can update only assigned stage/order.
- Repeated offline retry does not duplicate an update.
- Risk result shows its inputs and formula.
- Merchandiser can confirm/dismiss an alert.
- Buyer sees only own orders and approved photos.
- AI preserves original note and supports human correction/fallback.
- Important date changes and approvals appear in audit history.
