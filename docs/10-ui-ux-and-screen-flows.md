# UI/UX and screen flows

## Primary screens
1. Operations overview
2. Order setup and TNA
3. Order detail and milestone timeline
4. Supervisor daily update
5. Risk intelligence and alerts
6. Buyer portal
7. Audit history
8. Weekly reports

## Navigation
Merchandiser: Overview, Orders, Production, Risk & Alerts, Buyers, TNA Templates, Reports, Audit History, Settings.
Supervisor: My Work, Update, Sync Queue, Profile.
Buyer: My Orders, Order Details, Milestones, Approved Photos, Updates.

## Visual direction
Use generous whitespace, restrained colours, clear typography, tabular numerals, accessible contrast, and Tamil-capable font fallbacks. Suggested palette: deep forest `#172E32`, green `#246B59`, amber `#E5A43A`, red `#C84D4D`, warm background `#F4F6F4`, white.

Supervisor update should be optimized for a small Android screen: select assigned order/stage, enter good quantity, optional rejected quantity/photo/note, submit, and see sync state.
