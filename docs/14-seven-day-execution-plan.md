# Seven-day execution plan

## Day 1 — Foundation
Repository setup, Docker Compose, Express app, React app, Prisma connection, health check, auth skeleton.

## Day 2 — Orders and TNA
Order CRUD, buyer/unit relationships, milestone setup, seed data, validation.

## Day 3 — Supervisor workflow
Assigned work list, production update API, photo upload, idempotency, offline queue baseline.

## Day 4 — Order board and risk
Order filters, deterministic run-rate calculation, explainable alert lifecycle.

## Day 5 — Buyer portal and AI
Buyer isolation, approved photos, milestone view, asynchronous issue-note classification.

## Day 6 — Audit, reports, and tests
Audit events, weekly export, integration and authorization tests, security review.

## Day 7 — Stabilize and demo
Fix critical defects, deploy, seed demo, rehearse workflow, document assumptions and limitations.

Prioritize the end-to-end workflow. Voice transcription, elaborate analytics, and external integrations are optional if time is tight.
